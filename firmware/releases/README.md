# Built firmware

`firmware-<version>.bin` is the firmware with both wake methods (BLE and
2.4G/BT, chosen on the wake page). Built files are not committed; they are
attached to the matching release on the
[Releases page](https://github.com/marcinx64/bc-250-power/releases). Install
one from the web UI (Controller view, Update firmware) or over USB;
[docs/FLASHING.md](../../docs/FLASHING.md) explains both and how to build the
file.
